# Authored assets

Everything visual in this replica was drawn for it. No file, font or image was downloaded from the
reference site, and no SVG was copied from its DOM.

| Asset | Stands in for | How it was made |
| --- | --- | --- |
| Six-petal knot (`js/icons.js` → `MARK`, `assets/mark.svg`) | OpenAI blossom mark / favicon | Six rotated ellipses (rx 3.2, ry 6.1) around a 24px centre, 1.4 stroke. Authored geometry, used at 16–26px. |
| New chat | Square + pencil glyph | Rect with rounded corners, diagonal pencil; 1.6 stroke, 24 viewBox |
| Images | Photo frame | Rounded rect, sun dot, mountain path |
| Plugins | Two-pin plug | Pin stems, plug body, cable |
| Plans | Coin with “S” curve | Circle plus a stroked S and centre line |
| Help | Question mark | Circle plus arc and dot |
| Deep research | Magnifier with sparkle | Circle, handle, four-point star |
| Settings | Gear | Circle plus eight-lobe outline path |
| Mic / waveform / arrow / plus / chevrons | Composer controls | Simple strokes, 1.6–1.9 weight |
| Copy, thumbs, more, trash, close, panel, menu, search, check, external | Message and chrome actions | 24 viewBox line icons, 16–20px optical size |
| Google / Apple / phone marks | Social sign-in row | A “G” letter mark, an apple outline, a handset outline — authored shapes, not brand files |

Type is not shipped: the clone uses the same OS UI font stack the reference resolves to, so there is no
webfont to license or host.

No photography, illustration or texture appears on the captured pages, so none was substituted.
